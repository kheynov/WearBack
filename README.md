# WearBack

Простейшее приложение-утилита для Wear OS: запуск **WearBack** выполняет один системный
«Назад». Рассчитано на назначение на аппаратную кнопку штатными настройками часов.

## Сборка и установка

Android Studio / JDK 21, установленный Android SDK 36.1. Минимальный Android API — 30
(Wear OS 3 и новее); compile SDK 36.1, target SDK 36.
Путь к SDK задаётся локально через `local.properties` или `ANDROID_HOME`.

```sh
./gradlew :app:installUserDebug
```

После установки в настройках специальных возможностей необходимо включить WearBack
Затем в настройках элементов управление назначить WearBack на желаемую физическую кнопку
